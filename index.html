// 최상위 개요 · OVERVIEW

하늘에 또 하나의 도시가 나타났다.
그날 이후, 인류는 이상현상과 함께 살아간다.

현실과 똑같이 생긴 거대한 도시가 하늘에 나타난 초대형 이상현상. 처음엔 자연재해나 착시로 여겨졌지만, 그 공간은 실제로 존재했고 내부에 진입할 수 있었다. 이후 세계 곳곳에서 다양한 이상현상이 발생했고, 발생 원인과 장소는 지금까지도 사전에 예측할 수 없다.

이상현상관리국 C.L.E.A.R.은 이 정체불명의 현상을 감시·분석하고 통제하는 전문기관이다. 인류는 이상현상과 공존하고 있지만, 그 정체와 발생 원인에 대해서는 여전히 밝혀진 것이 거의 없다.

LOG.04

대응 전문기관이 설립되었고, 극히 일부의 노출자가 특별한 능력을 발현하기 시작했다.

이상현상 · 핵 · 이형체 ANOMALY / CORE / ENTITY

FILE ANM-001 · 이상현상CONFIDENTIAL

이상현상 ANOMALY

평범한 현대 사회에 갑작스럽게 발생하는, 현실의 물리 법칙과 상식으로는 설명할 수 없는 모든 비정상적인 현상과 공간의 통칭.

  • 형태와 규모가 다양 — 특정 장소·사물에 발생하는 현상부터 현실과 분리된 독립 공간까지. 같은 유형이라도 특성이 서로 다르다.
  • 고유한 규칙 — 각 이상현상에는 고유한 규칙이 존재하며, 무시하거나 조건을 충족하지 못하면 치명적인 결과가 발생할 수 있다.
  • 뒤틀린 내부 — 현실에 없는 생명체·물질·뒤틀린 공간이 나타나고, 내외부의 시간과 물리 법칙이 다르게 적용되기도 한다.
  • 예측 불가 — 발생 원인은 확인되지 않았고, 발생 장소를 사전에 예측하는 것도 불가능하다.
FILE CORE-002 · 핵 / 수호 이형체TOP PRIORITY

핵 & 수호 이형체 CORE / GUARDIAN

이상현상 내부에는 공간을 유지하는 핵이 존재한다. 핵을 파괴·제거하면 이상현상은 붕괴하여 소멸한다.

  • 핵의 형태·위치·제거 방법은 이상현상마다 다르다.
  • 규모가 크고 위험도가 높은 공간에는 핵을 지키는 강력한 이형체 한 마리가 존재하는 경우가 많다.
  • 핵 수호 이형체는 일반 이형체보다 압도적으로 강하며, 핵에 접근하는 존재를 적극적으로 공격한다.
  • 모든 이상현상에 수호 이형체가 있는 것은 아니며, 존재 여부·형태·능력은 제각각이다.
FILE ENT-003 · 이형체HAZARD

이형체 ENTITY

이상현상 공간 내부에서 발견되는 설명할 수 없는 존재들의 통칭. 대부분 이상현상 공간의 영향을 받는 것으로 추정된다.

  • 외형·크기·지능·행동 방식은 개체마다 크게 다르다.
  • 현실의 동물이나 인간과 유사한 형태부터 기괴하고 비정상적인 형태까지 다양하게 존재한다.

FILE ORG-000 · 기관 개요CLASSIFIED

설립 목적

세계 각지에서 발생하는 이상현상을 조사하고 관리하기 위해 설립된 전문기관. 이상현상을 단순히 제거하는 것을 넘어, 발생 원인과 핵의 정체, 이능력과의 연관성을 밝혀내는 것을 목표로 한다.

주요 임무

감시 · 분석현장 통제내부 탐사 핵 제거피해 수습이능력자 관리

현장 요원 · 등급 지정

현장 요원은 이상현상에 직접 진입해 내부를 조사하고 핵을 제거하는 위험한 임무를 수행한다. 위험등급은 규모 · 위험성 · 내부 환경 · 이형체 위협 수준을 종합해 지정된다.
